# DLsiteFloat - DLsiteSound 悬浮窗/状态栏字幕模块

**简体中文** | [繁體中文](README.zh-TW.md) | [English](README.en.md)

> 一个 LSPosed / Xposed 模块，在 DLsiteSound（DLsite 音频 App）的**播放页**上挂一个与播放进度同步的**悬浮字幕窗**；同时支持将字幕镜像到**系统状态栏**（在 SystemUI 进程内注入）。

- 当前版本：**2.4.2**（`DLsiteFloat-2.4.2-code1043-debug.apk`，包名 `io.github.ariinyume.dlsitesoundfloat`）

- 📝 开发进度：[DLsiteFloat插件开发进度管理](https://my.feishu.cn/wiki/CQoMwY4nFilzLkkrzG4cy44fnoh)
- ⭐ Xposed 仓库：[DLsiteFloat - DLSiteSound悬浮窗/状态栏字幕模块](https://github.com/Xposed-Modules-Repo/io.github.ariinyume.dlsitesoundfloat)

## 功能特点

- **播放页双胶囊按钮**：播放控制条上方并排两个 MD3 胶囊按钮 —— 左`状态栏 开 / 状态栏 关`（**无字幕时整个消失**），右`悬浮窗 开 / 悬浮窗 关 / 无字幕`。
  - `状态栏 关`：状态栏字幕已关闭
  - `状态栏 开`：状态栏字幕已打开
  - `悬浮窗 关`：悬浮窗已关闭
  - `悬浮窗 开`：悬浮窗已打开
  - `无字幕`：当前音轨没有可用字幕
  - **按钮尺寸固定**：宽高、圆角、文字、距滑条偏移只按**首次锁定的密度**计算；文字用**固定 px** 并按胶囊可用宽度自动适配，保证**完全显示**，也不受后续系统「字体大小 / 显示大小」变化影响。
  - **多语言支持**：按**系统语言**取插件显示语言（读系统配置，不受宿主 App 的「应用语言」影响），支持**简体中文 / 繁體中文 / English**。
    | 系统语言 | 左 / 右按钮 | 按钮`无字幕` | 悬浮窗占位 |
    | --- | --- | --- | --- |
    | 简体中文 | `状态栏 开 / 关`、`悬浮窗 开 / 关` | `无字幕` | `无字幕` |
    | 繁體中文 | `狀態欄 開 / 關`、`懸浮窗 開 / 關` | `無字幕` | `無字幕` |
    | 其它语言 | `Status ON / OFF`、`Popup ON / OFF` | `No Sub` | `No Subtitles` |
    
- **状态栏字幕**：把当前字幕行**镜像到系统状态栏** —— 在 SystemUI 进程里注入一个常驻 `FrameLayout`，由 App 进程**跨进程广播**推送字幕行。由播放页左侧的`状态栏 开 / 状态栏 关`胶囊按钮单击切换。详见 [docs/statusbar-subtitle.md](docs/statusbar-subtitle.md)。
  - **单程左移滚动**：按 cue 时长滚动，新行先静置再起滚，长字幕不再来回弹。
  - **遮挡时钟 / 通知图标区**：显示期间隐藏状态栏时钟与通知图标区，通知换成数字徽标；结束时还原。
  - **流体云避让**：字幕右界动态卡在流体云（`seeding_card_container`）左边；流体云不在时按固定左界（38dp）铺满。宽度带 24px 迟滞，避免流体云进出时宽度来回跳。

- **可视化设置页**：模块自带设置页，改完点「保存设置」即时生效。
  - **三张卡 + 三个页签**：字幕外观合成**一张**卡，卡内按 **`字幕` / `行态` / `排版`** 三个页签切换 —— 切换只改可见性，不重建控件、不丢未保存的改动；「液态玻璃」「实验性功能」「其他」仍是独立卡片。
  - **状态卡（吸顶）**：「模块是否已激活 / SystemUI 是否已授权 / DLsiteSound 是否在跑」三种状态各给对应指引，未激活时整页控件禁用；卡内显示**宿主版本与是否已验证**（形如「宿主 2.22.0 · 已验证」）；页面下滑时**吸顶**常驻。**连续点击状态卡五次**可解锁隐藏的「实验性功能」卡，见下。
  - **保存与撤销**：底部保存栏**悬浮**常驻，并显示「有 N 处未保存」；保存后提示条上可**一键撤销上一次保存**；有未保存改动时退出会二次确认（保存 / 不保存 / 取消）。
  - **主字幕 / 活动行**：主字幕颜色、阴影颜色、阴影强度、阴影半径、活动行不透明度、主字幕放大倍数。
  - **非活动行**：是否模糊非活动行 + 模糊半径、是否缩放非活动行 + 缩放比例。
  - **字幕排版**：对齐（左 / 居中 / 右）、字幕间行距、长字幕内换行额外行距、悬浮窗颜色。
  - **色板**：主字幕颜色 / 阴影颜色 / 悬浮窗颜色三处色板保留 **6 色 + 色板**（白、黑、绿、橙、青、紫）。
  - **恢复默认按页签拆开**：三个页签各有自己的「恢复字幕颜色默认设置 / 恢复行态默认设置 / 恢复排版默认设置」，**只重置本页签内的设置项**。
  - **实时预览窗**：调参过程中预览窗同步渲染；可折叠成三行，长字幕与自动换行都按真实排版渲染。
  - **液态玻璃效果调整**：独立成卡，总开关 + 四个滑条（环境背景亮度 / 通透度 / 明暗度 / 模糊强度）+ 恢复默认。
  - **语言**：页内即时切换 **简体中文 / 繁體中文 / English**（不跟随播放页按钮显示语言设定）。
  - **实验性功能**：用于收纳**尚在验证中、性能不稳定、可能有版权风险**的能力，**默认隐藏**。在设置页**连续点击状态卡五次**（相邻两次间隔不超过 3 秒）即可解锁，解锁后仍需点「保存设置」才写入配置。
    - **卡内总开关**：关闭时其下子功能**全部关闭**，但相关功能缓存仍需要用户在功能关闭前**自行**点击相关按钮清除（防手欠）。
    - **字幕缓存**：即上文的「字幕离线缓存」与「字幕预取」。卡内给**四行读数**（已缓存 N 轨 / 占用 X/Y / 命中 X/Y 次 / 预取 X 部·Y 轨，另加一行上屏行一致）；清理入口拆成**「清除已缓存字幕」与「清除预取字幕」两枚**。**每一行读数的口径、归零时机与常见误读**见 [docs/字幕缓存读数说明.md](docs/字幕缓存读数说明.md)。
  - **其他**：状态栏字幕功能总闸、**隐藏桌面图标**（默认关；开启隐藏后仍可从 LSPosed 模块列表打开；**不支持的机型会自动恢复显示并提示**）、**调试日志**开关（默认关）、字幕配置备份与恢复（导出 / 导入 JSON）、重启系统界面。

- **进程内悬浮窗**：窗口直接挂在 DLsiteSound 进程内（`WindowManager` + `TYPE_APPLICATION_OVERLAY`），与各个 Hook 共享同一个 `SubtitleRepository` 实例，**无需任何跨进程 IPC、无需独立 Service**。
  - **悬浮窗可拖动 / 可缩放**：面板任意处按住拖动移动；右下角手柄拖动缩放（默认 85% 屏宽 × 200dp，最小 140×72dp，**纵向最长不超过半屏**）。
  - **悬浮窗内关闭按钮两种收法**：点一次面板出现 ✕，**5s 内没点自动隐藏**；期间**再点面板空白处立即收回**。
  - **可单独使用悬浮窗字幕**：未授权 `com.android.systemui` 作用域时左侧`状态栏 开 / 状态栏 关`按钮不显示。

- **液态玻璃悬浮窗主题**：悬浮窗面板与播放页字幕按钮可切换为**液态玻璃**质感 ——「背景模糊」交给**系统合成器**做（零权限、零采集、零额外功耗），玻璃本身由模块自绘 8 层材质（圆角裁切 / 自适应霜面 / 顶底受光 / 颗粒霜化 / 折射边光 / 内圈细边光）。详细文档见 [docs/液态玻璃实现与可调参数.md](docs/液态玻璃实现与可调参数.md)。
  - **独立调节卡片**：设置页「**液态玻璃效果调整**」独立成卡 —— 液态玻璃（总开关）、环境背景亮度、通透度、明暗度、模糊强度、恢复液态玻璃默认设置。**总开关关闭时下方全部隐藏**。
  - 开了液态玻璃后，「悬浮窗颜色」不可调整（玻璃会盖住纯色底）。

- **按播放进度对齐字幕**：以播放器（`ExoPlayer` / expo 音频）真实播放进度为主轴对齐字幕行。

- **自动抓取字幕**：拦截 DLsiteSound 的网络响应（okhttp3），直接扫描响应体是否包含 `webvtt` / `subtitles` 字幕 JSON 并解析——**不依赖 URL 关键词**，对混淆/重打包的 okhttp3 也能兜底。字幕源为 DLsiteSound 官方 `play.dl.dlsitesound.com/.../optimized/xxx.json`，按音轨下发。

- **字幕离线缓存（属于实验性功能）**：**在线播放过的音轨**，其字幕会自动缓存到本机 —— 之后**断网 / 飞行模式 / 不挂代理**时照常显示。缓存只保存官方下发的那份**字幕文本**（按音轨存），不涉及任何音频内容。
  - **只对「已经播过」的音轨生效**：从没在线抓到过字幕的音轨，离线时仍然没有字幕。
  - **按「作品 + 音轨身份」存**：身份取 `(音轨数, 时长, 序号)` 三元组 —— 换章节、换音轨、播放列表重建都不会串轨；时间轴对不上的条目会被**自动判定为错标并丢弃**。
  - **自动清理**：超出储存上限后**按最早缓存顺序自动清除**。
  - **缓存位置**：宿主 App 私有目录 `Android/data/jp.co.eisys.dlsitesound/files/subtitle_cache/`；占用读数与「清除字幕缓存」入口在设置页「**实验性功能**」卡里（该卡默认隐藏，见下）。**「已缓存 N 轨」「占用 X/Y」「命中 X/Y 次」这几行读数各是什么口径、什么时候会归零**，见 [docs/字幕缓存读数说明.md](docs/字幕缓存读数说明.md)。
  - ⚠️ **升级后可能看到缓存「清零」一次**：模块升级若改动了缓存格式，旧缓存会**整批作废重建** —— 设置页的占用读数会归零，把作品重新播一遍就会回来。

- **字幕预取（属于实验性功能）**：在线打开一部作品的播放页时，模块会顺手把该作品压缩包文件树里**全部音轨**的字幕**提前抓到本地** —— 之后在这个作品里任意换轨都能立刻出字幕，不用等云端那份 JSON。
  - **预存上限 16 部**：超出后按**最早预取的作品**整部淘汰；预取清空入口见上（「清除预取字幕」）。
  - **不占「字幕缓存」的配额**：预取单独计数与淘汰，所以设置页里「占用」**不含**预取那部分磁盘占用。
  - 换轨时仍**云端优先**：云端那份能按时到就用云端的（最新），到不了才回退到预取/缓存那份。

- **换轨智能处理**：切到无字幕音轨时先挂起、悬浮窗显示`无字幕`占位，等新音轨的字幕 JSON —— 无缓存 cues 时等 **1s**，已有缓存 cues 时放宽到 **15s**；等待期间还没等到 JSON 就**提前收窗**，JSON 到了会**自动把窗口开回**；直到裁决窗到点仍无 JSON，才清空 cues 并判「无字幕」。详见 [docs/track-change.md](docs/track-change.md)。
  - **云端优先、本地兜底**：换轨后**先等云端**那份最新字幕；窗口内等不到（无网络 / 云端慢）才回退到**本地已缓存**的那份，完全离线（飞行模式）时则直接读本地。

- **权限引导与降级**：未授予悬浮窗权限时，首次点击会跳到"在其他应用上层显示"设置页，且**只提示一次**。

- **常开日志收敛**：不打开调试开关时，日志里只留挂载与一次性探针、换轨结论、全部失败与告警、你的主动操作，以及行一致观测的**每分钟一行**汇总 —— 正常看一集不会再刷满屏。

## 适配范围

| 项目 | 说明 |
| --- | --- |
| **目标 App** | DLsiteSound（`jp.co.eisys.dlsitesound`） |
| **框架** | LSPosed **2.2.0+**（2.0.0 起改用 libxposed 现代 API，legacy API 与 modern API 不可混用） |
| **作用域** | 需勾选**两个**：`jp.co.eisys.dlsitesound`（宿主 App：悬浮窗 + 播放页按钮）与 `com.android.systemui`（状态栏字幕） |
| **libxposed API** | `minApiVersion=101` / `targetApiVersion=102`，配置在 `META-INF/xposed/module.prop`。2.0.0 起**不再**使用 `de.robv.android.xposed:api:82` 与四个 `xposed*` meta-data |
| **Android 版本** | `minSdk 24`（Android 7.0）起；`targetSdk / compileSdk 36`（2.3.5 起升到 Android 16，同时接上 edge-to-edge 的 insets）。Android 8.0+ 用 `TYPE_APPLICATION_OVERLAY`，更低版本回退 `TYPE_PHONE` |
| **机型 / ROM** | 针对 **ONEPLUS / ColorOS** 做了测试与适配，理论上支持 OxygenOS/RealmeUI；其它厂商 ROM 若悬浮窗/权限逻辑正常也应可用 |
| **生效条件** | 仅当该音轨由官方服务端提供字幕（optimized 字幕 JSON）时生效 |
| **不适用** | 非 DLsiteSound 的 App；未 root 或未安装 Xposed 框架的设备；DRM 受限内容本身无字幕的情况 |

> ⚠️ 适配依赖目标 App 的内部实现（视图结构、播放器类名、网络栈），**App 大版本更新可能导致模块失效**，需随版本重新适配。

## 使用方式

1. **获取模块**：自行构建（见 [docs/build.md](docs/build.md)），或从发布页下载 `DLsiteFloat-<版本>-debug.apk`。全部设置项说明见 [docs/settings.md](docs/settings.md)。
2. **安装并启用**：把 APK 装到已 root 设备 → 打开 **LSPosed Manager** 或同类插件管理器 → 启用本模块 → 作用域**两个都勾**：**`jp.co.eisys.dlsitesound`** + **`com.android.systemui`** → **强制停止** DLsiteSound，并**重启 SystemUI 或重启手机**。
3. **授予悬浮窗权限**：
   - 设置 → 应用 → DLsiteSound & DLsiteFloat → 权限管理 → 特殊应用权限 → `悬浮窗`。
4. **打开有字幕的播放页**：播放控制条上方出现两个胶囊按钮。
   - 左`状态栏 开 / 状态栏 关`：单击开关**状态栏字幕**（默认关）；无字幕或未授权 `com.android.systemui` 作用域时该按钮不出现。
   - 右`悬浮窗 开 / 悬浮窗 关`：单击开关**悬浮窗**。
   - 无字幕时显示`无字幕`且悬浮窗不可开。
   - 离开播放页（回到首页 / 列表页等）按钮自动隐藏；悬浮窗与状态栏字幕都不随页面隐藏。
5. **操作悬浮窗**：面板任意处按住拖动可移动；右下角手柄拖动可缩放。点面板（非手柄）可切换右上角关闭按钮（✕，30dp 显示 / 点击区）的显隐；点 ✕ 关闭窗口。
6. 悬浮窗字幕和状态栏字幕可同时使用，二者相互不干扰。
7. **调字幕外观**：桌面图标 **「DLsiteFloat 设置」** / 插件管理器中找到本插件 进可视化设置页 —— 字幕外观是**一张卡三个页签**（`字幕` / `行态` / `排版`），切页签不丢未保存的改动；改完点底部悬浮的「保存设置」即生效，点错了可在提示条上**撤销**（状态栏字幕的相关改动需要「重启系统界面」才会刷新）。
8. **想要液态玻璃效果**：同一设置页 →「液态玻璃效果调整」卡 → 打开总开关，再按喜好调四个滑条（**环境背景亮度**按当前页面明暗填，其余三项默认 `50` 即可）→ 点「保存设置」生效。
