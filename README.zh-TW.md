# DLsiteFloat - DLsiteSound 懸浮窗/狀態欄字幕模組

[简体中文](README.md) | **繁體中文** | [English](README.en.md)

> 一個 LSPosed / Xposed 模組，在 DLsiteSound（DLsite 音訊 App）的**播放頁**上掛一個與播放進度同步的**懸浮字幕窗**；同時支援將字幕鏡像到**系統狀態欄**（在 SystemUI 程序內注入）。

- 目前版本：**2.3.1**（`DLsiteFloat-2.3.1-code1006-debug.apk`，套件名稱 `io.github.ariinyume.dlsitesoundfloat`）
- 📦 下載 APK：[Releases · v2.3.1](https://github.com/ariinyume/DLSiteSoundFloatingSubtitle/releases/tag/v2.3.1)
- 📝 開發進度：[DLsiteFloat 外掛開發進度管理](https://my.feishu.cn/wiki/CQoMwY4nFilzLkkrzG4cy44fnoh)
- ⭐ Xposed 倉庫：[DLsiteFloat - DLsiteSound 懸浮窗/狀態欄字幕模組](https://github.com/Xposed-Modules-Repo/io.github.ariinyume.dlsitesoundfloat)

## 功能特點

- **播放頁雙膠囊按鈕（2.0.1 起）**：播放控制列上方並排兩個 MD3 膠囊按鈕 —— 左`狀態欄 開 / 狀態欄 關`（**無字幕時整個消失**），右`懸浮窗 開 / 懸浮窗 關 / 無字幕`。
  - `狀態欄 關`：狀態欄字幕已關閉
  - `狀態欄 開`：狀態欄字幕已開啟
  - `懸浮窗 關`：懸浮窗已關閉
  - `懸浮窗 開`：懸浮窗已開啟
  - `無字幕`：目前音軌沒有可用字幕
  - **按鈕尺寸固定（2.1.2 起）**：寬高、圓角、文字、距滑桿偏移只按**首次鎖定的密度**計算；文字用**固定 px** 並按膠囊可用寬度自動適配，保證**完全顯示**，也不受後續系統「字型大小 / 顯示大小」變化影響。
  - **多語言支援（2.1.2 起）**：按**系統語言**取外掛顯示語言（讀系統設定，不受宿主 App 的「應用程式語言」影響），支援**简体中文 / 繁體中文 / English**。
    | 系統語言 | 左 / 右按鈕 | 按鈕`無字幕` | 懸浮窗佔位 |
    | --- | --- | --- | --- |
    | 简体中文 | `状态栏 开 / 关`、`悬浮窗 开 / 关` | `无字幕` | `无字幕` |
    | 繁體中文 | `狀態欄 開 / 關`、`懸浮窗 開 / 關` | `無字幕` | `無字幕` |
    | 其他語言 | `Status ON / OFF`、`Popup ON / OFF` | `No Sub` | `No Subtitles` |
    
- **狀態欄字幕（2.0.1 起）**：把目前字幕行**鏡像到系統狀態欄** —— 在 SystemUI 程序裡注入一個常駐 `FrameLayout`，由 App 程序**跨程序廣播**推送字幕行。由播放頁左側的`狀態欄 開 / 狀態欄 關`膠囊按鈕單擊切換。詳見 [docs/statusbar-subtitle.md](docs/statusbar-subtitle.md)。
  - **單程左移捲動**（取代系統跑馬燈的循環回彈）：按 cue 時長捲動，新行先靜止再起捲，長字幕不再來回彈。
  - **遮擋時鐘 / 通知圖示區**：顯示期間隱藏狀態欄時鐘與通知圖示區，通知換成數字徽章；結束時還原。
  - **流體雲避讓**：字幕右界動態卡在流體雲（`seeding_card_container`）左邊；流體雲不在時按固定左界（38dp）鋪滿。寬度帶 24px 遲滯，避免流體雲進出時寬度來回跳。

- **視覺化設定頁（2.2.0 起）**：模組自帶設定頁，改完點「儲存設定」即時生效。
  - **狀態卡**：「模組是否已啟用 / SystemUI 是否已授權 / DLsiteSound 是否在跑」三種狀態各給對應指引，未啟用時整頁控制項停用。
  - **主字幕 / 活動行**：主字幕顏色、陰影顏色、陰影強度、陰影半徑、活動行不透明度、主字幕放大倍數。
  - **非活動行**：是否模糊非活動行 + 模糊半徑、是否縮放非活動行 + 縮放比例。
  - **字幕排版**：對齊（靠左 / 置中 / 靠右）、字幕間行距、長字幕內換行額外行距、懸浮窗顏色。
  - **即時預覽窗**：調參過程中預覽窗同步算繪。
  - **液態玻璃效果調整**（2.3.0 起）：獨立成卡，擺在「其他」卡**之前**；總開關 + 四個滑桿（環境背景亮度 / 通透度 / 明暗度 / 模糊強度）+ 恢復預設。
  - **語言**：頁內即時切換 **简体中文 / 繁體中文 / English**（不跟隨播放頁按鈕顯示語言設定）。
  - **其他**：狀態欄字幕功能總開關、**偵錯日誌**開關（2.2.7 起，預設關）、字幕設定備份與恢復（匯出 / 匯入 JSON）、重啟系統介面。

- **程序內懸浮窗**：視窗直接掛在 DLsiteSound 程序內（`WindowManager` + `TYPE_APPLICATION_OVERLAY`），與各個 Hook 共享同一個 `SubtitleRepository` 實例，**無需任何跨程序 IPC、無需獨立 Service**。
  - **懸浮窗可拖曳 / 可縮放**：面板任意處按住拖曳移動；右下角把手拖曳縮放（預設 85% 螢幕寬 × 200dp，最小 140×72dp，**縱向最長不超過半螢幕**）。
  - **懸浮窗內關閉按鈕兩種收法**：點一次面板出現 ✕，**5s 內沒點自動隱藏**；期間**再點面板空白處立即收回**。
  - **可單獨使用懸浮窗字幕**：未授權 `com.android.systemui` 作用域時左側`狀態欄 開 / 狀態欄 關`按鈕不顯示。

- **液態玻璃懸浮窗（2.3.0 起）**：懸浮窗面板與播放頁字幕按鈕可切換為**液態玻璃**質感 ——「背景模糊」交給**系統合成器**做（零權限、零擷取、零額外功耗），玻璃本身由模組自繪 8 層材質（圓角裁切 / 自適應霜面 / 頂底受光 / 顆粒霜化 / 折射邊光 / 內圈細邊光）。詳細文件見 [docs/液态玻璃实现与可调参数.md](docs/液态玻璃实现与可调参数.md)。
  - **獨立調節卡片**：設定頁「**液態玻璃效果調整**」獨立成卡 —— 液態玻璃（總開關）、環境背景亮度、通透度、明暗度、模糊強度、恢復液態玻璃預設設定。**總開關關閉時下方全部隱藏**。
  - 開了液態玻璃後，「懸浮窗顏色」無法調整（玻璃會蓋住純色底）。

- **依播放進度對齊字幕**：以播放器（`ExoPlayer` / expo 音訊）真實播放進度為主軸對齊字幕行。

- **自動擷取字幕**：攔截 DLsiteSound 的網路回應（okhttp3），直接掃描回應主體是否包含 `webvtt` / `subtitles` 字幕 JSON 並解析——**不依賴 URL 關鍵字**，對混淆/重打包的 okhttp3 也能作為後備。字幕來源為 DLsiteSound 官方 `play.dl.dlsitesound.com/.../optimized/xxx.json`，按音軌下發。

- **換軌智慧處理**：切到無字幕音軌時先掛起、懸浮窗顯示`無字幕`佔位，等新音軌的字幕 JSON —— 無快取 cues 時等 **5s**，已有快取 cues 時放寬到 **15s**；**5s**內還沒等到 JSON 就**提前收窗**，JSON 到了會**自動把視窗開回**；直到裁決窗到點仍無 JSON，才清空 cues 並判「無字幕」。詳見 [docs/track-change.md](docs/track-change.md)。

- **權限引導與降級**：未授予懸浮窗權限時，首次點擊會跳到「在其他應用程式上層顯示」設定頁，且**只提示一次**。

## 適用範圍

| 項目 | 說明 |
| --- | --- |
| **目標 App** | DLsiteSound（`jp.co.eisys.dlsitesound`） |
| **框架** | LSPosed **2.2.0+**（2.0.0 起改用 libxposed 現代 API，legacy API 與 modern API 不可混用） |
| **作用域** | 需勾選**兩個**：`jp.co.eisys.dlsitesound`（宿主 App：懸浮窗 + 播放頁按鈕）與 `com.android.systemui`（狀態欄字幕） |
| **libxposed API** | `minApiVersion=101` / `targetApiVersion=102`，設定在 `META-INF/xposed/module.prop`。2.0.0 起**不再**使用 `de.robv.android.xposed:api:82` 與四個 `xposed*` meta-data |
| **Android 版本** | `minSdk 24`（Android 7.0）起；`targetSdk / compileSdk 34`。Android 8.0+ 用 `TYPE_APPLICATION_OVERLAY`，更低版本回退 `TYPE_PHONE` |
| **機型 / ROM** | 針對 **ONEPLUS / ColorOS** 做了測試與適配，理論上支援 OxygenOS/RealmeUI；其他廠商 ROM 若懸浮窗/權限邏輯正常也應可用 |
| **生效條件** | 僅當該音軌由官方伺服器提供字幕（optimized 字幕 JSON）時生效 |
| **不適用** | 非 DLsiteSound 的 App；未 root 或未安裝 Xposed 框架的裝置；DRM 受限內容本身無字幕的情況 |

> ⚠️ 適配依賴目標 App 的內部實作（檢視結構、播放器類別名稱、網路堆疊），**App 大版本更新可能導致模組失效**，需隨版本重新適配。

## 使用方式

1. **取得模組**：自行建置（見 [docs/build.md](docs/build.md)），或從發布頁下載 `DLsiteFloat-<版本>-debug.apk`。全部設定項說明見 [docs/settings.md](docs/settings.md)。
2. **安裝並啟用**：把 APK 裝到已 root 裝置 → 開啟 **LSPosed Manager** 或同類外掛管理器 → 啟用本模組 → 作用域**兩個都勾**：**`jp.co.eisys.dlsitesound`** + **`com.android.systemui`** → **強制停止** DLsiteSound，並**重啟 SystemUI 或重啟手機**。
3. **授予懸浮窗權限**：
   - 設定 → 應用程式 → DLsiteSound & DLsiteFloat → 權限管理 → 特殊應用程式權限 → `懸浮窗`。
   - 如有需要，可允許`背景彈出介面`
4. **開啟有字幕的播放頁**：播放控制列上方出現兩個膠囊按鈕。
   - 左`狀態欄 開 / 狀態欄 關`：單擊開關**狀態欄字幕**（預設關）；無字幕或未授權 `com.android.systemui` 作用域時該按鈕不出現。
   - 右`懸浮窗 開 / 懸浮窗 關`：單擊開關**懸浮窗**。
   - 無字幕時顯示`無字幕`且懸浮窗不可開。
   - 離開播放頁（回到首頁 / 清單頁等）按鈕自動隱藏；懸浮窗與狀態欄字幕都不隨頁面隱藏。
5. **操作懸浮窗**：面板任意處按住拖曳可移動；右下角把手拖曳可縮放。點面板（非把手）可切換右上角關閉按鈕（✕，30dp 顯示 / 點擊區）的顯示與否；點 ✕ 關閉視窗。
6. 懸浮窗字幕和狀態欄字幕可同時使用，二者互不干擾。
7. **調字幕外觀**：桌面圖示 **「DLsiteFloat 设置」** / 外掛管理員中找到本外掛 進視覺化設定頁，改完點「儲存設定」即生效（狀態欄字幕的相關變更需要「重啟系統介面」才會重新整理）。
8. **想要液態玻璃效果**：同一設定頁 →「液態玻璃效果調整」卡 → 打開總開關，再依喜好調四個滑桿（**環境背景亮度**依目前頁面明暗填，其餘三項預設 `50` 即可）→ 點「儲存設定」生效。

## 意見回饋

- **GitHub Issues**：請在專案倉庫的 Issues 區提交，並盡量附上：
  1. 你的裝置型號 / Android 版本 / ROM（尤其是否 ColorOS / 澎湃 / 原生 / 類原生 等）
  2. 使用的 DLsiteSound 版本號
  3. 重現步驟 + LSPosed 日誌（`DLsiteSoundFloat` 過濾）+ 必要時 `dlsitefloat_net.log`+ 螢幕錄影 / 螢幕截圖（請給敏感資訊打碼或裁切）
- **提交前請先確認**：裝的是不是最新 APK（看 LSPosed 日誌裡 `==== BUILD 2.3.1 / code 1006` 那一行）
- **排查換軌 / 字幕擷取類問題時**：請在設定頁「其他」裡開啟**偵錯日誌**再重現一次（預設關閉，開久了會刷屏；重現完記得關掉）。
- **液態玻璃效果類問題**：請先試「模糊強度調回 50~60」「通透度不要拉滿」「依頁面明暗調環境背景亮度」；仍異常請附 LSPosed 日誌（`DLsiteSoundFloat` 過濾），並說明**機型 / ROM**（不同 ROM 的合成器模糊支援度不同）。

- 提交 Issue：<https://github.com/ariinyume/DLSiteSoundFloatingSubtitle/issues>
