# DLsiteFloat - DLsiteSound 懸浮窗/狀態欄字幕模組

[简体中文](README.md) | **繁體中文** | [English](README.en.md)

> 一個 LSPosed / Xposed 模組，在 DLsiteSound（DLsite 音訊 App）的**播放頁**上掛一個與播放進度同步的**懸浮字幕窗**；同時支援將字幕鏡像到**系統狀態欄**（在 SystemUI 程序內注入）。

## 功能特點

- **播放頁雙膠囊按鈕**：播放控制列上方並排兩個 MD3 膠囊按鈕 —— 左`狀態欄 開 / 狀態欄 關`（**無字幕時整個消失**），右`懸浮窗 開 / 懸浮窗 關 / 無字幕`。
  - `狀態欄 關`：狀態欄字幕已關閉
  - `狀態欄 開`：狀態欄字幕已開啟
  - `懸浮窗 關`：懸浮窗已關閉
  - `懸浮窗 開`：懸浮窗已開啟
  - `無字幕`：目前音軌沒有可用字幕
  - **按鈕尺寸固定**：寬高、圓角、文字、距滑桿偏移只按**首次鎖定的密度**計算；文字用**固定 px** 並按膠囊可用寬度自動適配，保證**完全顯示**，也不受後續系統「字型大小 / 顯示大小」變化影響。
  - **多語言支援**：按**系統語言**取外掛顯示語言（讀系統設定，不受宿主 App 的「應用程式語言」影響），支援**简体中文 / 繁體中文 / English**。
    | 系統語言 | 左 / 右按鈕 | 按鈕`無字幕` | 懸浮窗佔位 |
    | --- | --- | --- | --- |
    | 简体中文 | `状态栏 开 / 关`、`悬浮窗 开 / 关` | `无字幕` | `无字幕` |
    | 繁體中文 | `狀態欄 開 / 關`、`懸浮窗 開 / 關` | `無字幕` | `無字幕` |
    | 其他語言 | `Status ON / OFF`、`Popup ON / OFF` | `No Sub` | `No Subtitles` |
    
- **狀態欄字幕**：把目前字幕行**鏡像到系統狀態欄** —— 在 SystemUI 程序裡注入一個常駐 `FrameLayout`，由 App 程序**跨程序廣播**推送字幕行。由播放頁左側的`狀態欄 開 / 狀態欄 關`膠囊按鈕單擊切換。詳見 [docs/statusbar-subtitle.md](docs/statusbar-subtitle.md)。
  - **單程左移捲動**：按 cue 時長捲動，新行先靜止再起捲，長字幕不再來回彈。
  - **遮擋時鐘 / 通知圖示區**：顯示期間隱藏狀態欄時鐘與通知圖示區，通知換成數字徽章；結束時還原。
  - **流體雲避讓**：字幕右界動態卡在流體雲（`seeding_card_container`）左邊；流體雲不在時按固定左界（38dp）鋪滿。寬度帶 24px 遲滯，避免流體雲進出時寬度來回跳。

- **視覺化設定頁**：模組自帶設定頁，改完點「儲存設定」即時生效。
  - **三張卡 + 三個頁籤**：字幕外觀合成**一張**卡，卡內按 **`字幕` / `行態` / `排版`** 三個頁籤切換 —— 切換只改可見性，不重建控制項、不丟未儲存的變更；「液態玻璃」「實驗性功能」「其他」仍是獨立卡片。
  - **狀態卡（吸頂）**：「模組是否已啟用 / SystemUI 是否已授權 / DLsiteSound 是否在跑」三種狀態各給對應指引，未啟用時整頁控制項停用；卡內顯示**宿主版本與是否已驗證**（形如「宿主 2.22.0 · 已驗證」）；頁面下滑時**吸頂**常駐。**連續點擊狀態卡五次**可解鎖隱藏的「實驗性功能」卡，見下。
  - **儲存與撤銷**：底部儲存列**懸浮**常駐，並顯示「有 N 處未儲存」；儲存後提示條上可**一鍵撤銷上一次儲存**；有未儲存變更時離開會二次確認（儲存 / 不儲存 / 取消）。
  - **主字幕 / 活動行**：主字幕顏色、陰影顏色、陰影強度、陰影半徑、活動行不透明度、主字幕放大倍數。
  - **非活動行**：是否模糊非活動行 + 模糊半徑、是否縮放非活動行 + 縮放比例。
  - **字幕排版**：對齊（靠左 / 置中 / 靠右）、字幕間行距、長字幕內換行額外行距、懸浮窗顏色。
  - **色板**：主字幕顏色 / 陰影顏色 / 懸浮窗顏色三處色板保留 **6 色 + 色板**（白、黑、綠、橙、青、紫）。
  - **恢復預設按頁籤拆開**：三個頁籤各有自己的「恢復字幕顏色預設設定 / 恢復行態預設設定 / 恢復排版預設設定」，**只重設本頁籤內的設定項**。
  - **即時預覽窗**：調參過程中預覽窗同步算繪；可摺疊成三行，長字幕與自動換行都按真實排版算繪。
  - **液態玻璃效果調整**：獨立成卡，總開關 + 四個滑桿（環境背景亮度 / 通透度 / 明暗度 / 模糊強度）+ 恢復預設。
  - **語言**：頁內即時切換 **简体中文 / 繁體中文 / English**（不跟隨播放頁按鈕顯示語言設定）。
  - **實驗性功能**：用來收納**仍在驗證中、效能不穩定、可能有著作權風險**的能力，**預設隱藏**。在設定頁**連續點擊狀態卡五次**（相鄰兩次間隔不超過 3 秒）即可解鎖，解鎖後仍需按「儲存設定」才會寫入設定。
    - **卡內總開關**：關閉時其下子功能**全部關閉**，但相關功能快取仍需要使用者在功能關閉前**自行**點擊相關按鈕清除（防手殘）。
    - **字幕快取**：即上文的「字幕離線快取」與「字幕預取」。卡內給**四行讀數**（已快取 N 軌 / 佔用 X/Y / 命中 X/Y 次 / 預取 X 部·Y 軌，另加一行上屏行一致）；清理入口拆成**「清除已快取字幕」與「清除預取字幕」兩枚**。**每一行讀數的口徑、歸零時機與常見誤讀**見 [docs/字幕缓存读数说明.md](docs/字幕缓存读数说明.md)。
  - **其他**：狀態欄字幕功能總開關、**隱藏桌面圖示**（預設關；開啟隱藏後仍可從 LSPosed 模組清單開啟；**不支援的機型會自動恢復顯示並提示**）、**偵錯日誌**開關（預設關）、字幕設定備份與恢復（匯出 / 匯入 JSON）、重啟系統介面。

- **程序內懸浮窗**：視窗直接掛在 DLsiteSound 程序內（`WindowManager` + `TYPE_APPLICATION_OVERLAY`），與各個 Hook 共享同一個 `SubtitleRepository` 實例，**無需任何跨程序 IPC、無需獨立 Service**。
  - **懸浮窗可拖曳 / 可縮放**：面板任意處按住拖曳移動；右下角把手拖曳縮放（預設 85% 螢幕寬 × 200dp，最小 140×72dp，**縱向最長不超過半螢幕**）。
  - **懸浮窗內關閉按鈕兩種收法**：點一次面板出現 ✕，**5s 內沒點自動隱藏**；期間**再點面板空白處立即收回**。
  - **可單獨使用懸浮窗字幕**：未授權 `com.android.systemui` 作用域時左側`狀態欄 開 / 狀態欄 關`按鈕不顯示。

- **液態玻璃懸浮窗主題**：懸浮窗面板與播放頁字幕按鈕可切換為**液態玻璃**質感 ——「背景模糊」交給**系統合成器**做（零權限、零擷取、零額外功耗），玻璃本身由模組自繪 8 層材質（圓角裁切 / 自適應霜面 / 頂底受光 / 顆粒霜化 / 折射邊光 / 內圈細邊光）。詳細文件見 [docs/液态玻璃实现与可调参数.md](docs/液态玻璃实现与可调参数.md)。
  - **獨立調節卡片**：設定頁「**液態玻璃效果調整**」獨立成卡 —— 液態玻璃（總開關）、環境背景亮度、通透度、明暗度、模糊強度、恢復液態玻璃預設設定。**總開關關閉時下方全部隱藏**。
  - 開了液態玻璃後，「懸浮窗顏色」無法調整（玻璃會蓋住純色底）。

- **依播放進度對齊字幕**：以播放器（`ExoPlayer` / expo 音訊）真實播放進度為主軸對齊字幕行。

- **自動擷取字幕**：攔截 DLsiteSound 的網路回應（okhttp3），直接掃描回應主體是否包含 `webvtt` / `subtitles` 字幕 JSON 並解析——**不依賴 URL 關鍵字**，對混淆/重打包的 okhttp3 也能作為後備。字幕來源為 DLsiteSound 官方 `play.dl.dlsitesound.com/.../optimized/xxx.json`，按音軌下發。

- **字幕離線快取（屬於實驗性功能）**：**曾經線上播放過的音軌**，其字幕會自動快取到本機 —— 之後**斷網 / 飛航模式 / 不掛代理**時照常顯示。快取只保存官方下發的那份**字幕文字**（按音軌存），不涉及任何音訊內容。
  - **只對「已經播過」的音軌生效**：從未線上抓到過字幕的音軌，離線時仍然沒有字幕。
  - **按「作品 + 音軌身分」存**：身分取 `(音軌數, 時長, 序號)` 三元組 —— 換章節、換音軌、播放清單重建都不會串軌；時間軸對不上的項目會被**自動判定為錯標並丟棄**。
  - **自動清理**：超出儲存上限後**依最早快取順序自動清除**。
  - **快取位置**：宿主 App 私有目錄 `Android/data/jp.co.eisys.dlsitesound/files/subtitle_cache/`；佔用讀數與「清除字幕快取」入口在設定頁「**實驗性功能**」卡裡（該卡預設隱藏，見下）。**「已快取 N 軌」「佔用 X/Y」「命中 X/Y 次」這幾行讀數各是什麼口徑、什麼時候會歸零**，見 [docs/字幕缓存读数说明.md](docs/字幕缓存读数说明.md)。
  - ⚠️ **升級後可能看到快取「歸零」一次**：模組升級若改動了快取格式，舊快取會**整批作廢重建** —— 設定頁的佔用讀數會歸零，把作品重新播一遍就會回來。

- **字幕預取（屬於實驗性功能）**：線上打開一部作品的播放頁時，模組會順手把該作品壓縮檔檔案樹裡**全部音軌**的字幕**提前抓到本機** —— 之後在這個作品裡任意換軌都能立刻出字幕，不用等雲端那份 JSON。
  - **預存上限 16 部**：超出後按**最早預取的作品**整部淘汰；預取清空入口見上（「清除預取字幕」）。
  - **不佔「字幕快取」的配額**：預取單獨計數與淘汰，所以設定頁裡「佔用」**不含**預取那部分磁碟佔用。
  - 換軌時仍**雲端優先**：雲端那份能按時到就用雲端的（最新），到不了才退回預取/快取那份。

- **換軌智慧處理**：切到無字幕音軌時先掛起、懸浮窗顯示`無字幕`佔位，等新音軌的字幕 JSON —— 無快取 cues 時等 **1s**，已有快取 cues 時放寬到 **15s**；等待期間還沒等到 JSON 就**提前收窗**，JSON 到了會**自動把視窗開回**；直到裁決窗到點仍無 JSON，才清空 cues 並判「無字幕」。詳見 [docs/track-change.md](docs/track-change.md)。
  - **雲端優先、本機後備**：換軌後**先等雲端**那份最新字幕；視窗內等不到（沒有網路 / 雲端太慢）才退回**本機已快取**的那份，完全離線（飛航模式）時則直接讀本機。

- **權限引導與降級**：未授予懸浮窗權限時，首次點擊會跳到「在其他應用程式上層顯示」設定頁，且**只提示一次**。

- **常開日誌收斂**：不打開偵錯開關時，日誌裡只留掛載與一次性探針、換軌結論、全部失敗與告警、你的主動操作，以及行一致觀測的**每分鐘一行**彙總 —— 正常看一集不會再刷滿屏。

## 適用範圍

| 項目 | 說明 |
| --- | --- |
| **目標 App** | DLsiteSound（`jp.co.eisys.dlsitesound`） |
| **框架** | LSPosed **2.2.0+**（2.0.0 起改用 libxposed 現代 API，legacy API 與 modern API 不可混用） |
| **作用域** | 需勾選**兩個**：`jp.co.eisys.dlsitesound`（宿主 App：懸浮窗 + 播放頁按鈕）與 `com.android.systemui`（狀態欄字幕） |
| **libxposed API** | `minApiVersion=101` / `targetApiVersion=102`，設定在 `META-INF/xposed/module.prop`。2.0.0 起**不再**使用 `de.robv.android.xposed:api:82` 與四個 `xposed*` meta-data |
| **Android 版本** | `minSdk 24`（Android 7.0）起；`targetSdk / compileSdk 36`（2.3.5 起升到 Android 16，同時接上 edge-to-edge 的 insets）。Android 8.0+ 用 `TYPE_APPLICATION_OVERLAY`，更低版本回退 `TYPE_PHONE` |
| **機型 / ROM** | 針對 **ONEPLUS / ColorOS** 做了測試與適配，理論上支援 OxygenOS/RealmeUI；其他廠商 ROM 若懸浮窗/權限邏輯正常也應可用 |
| **生效條件** | 僅當該音軌由官方伺服器提供字幕（optimized 字幕 JSON）時生效 |
| **不適用** | 非 DLsiteSound 的 App；未 root 或未安裝 Xposed 框架的裝置；DRM 受限內容本身無字幕的情況 |

> ⚠️ 適配依賴目標 App 的內部實作（檢視結構、播放器類別名稱、網路堆疊），**App 大版本更新可能導致模組失效**，需隨版本重新適配。

## 使用方式

1. **取得模組**：自行建置（見 [docs/build.md](docs/build.md)），或從發布頁下載 `DLsiteFloat-<版本>-debug.apk`。全部設定項說明見 [docs/settings.md](docs/settings.md)。
2. **安裝並啟用**：把 APK 裝到已 root 裝置 → 開啟 **LSPosed Manager** 或同類外掛管理器 → 啟用本模組 → 作用域**兩個都勾**：**`jp.co.eisys.dlsitesound`** + **`com.android.systemui`** → **強制停止** DLsiteSound，並**重啟 SystemUI 或重啟手機**。
3. **授予懸浮窗權限**：
   - 設定 → 應用程式 → DLsiteSound & DLsiteFloat → 權限管理 → 特殊應用程式權限 → `懸浮窗`。
4. **開啟有字幕的播放頁**：播放控制列上方出現兩個膠囊按鈕。
   - 左`狀態欄 開 / 狀態欄 關`：單擊開關**狀態欄字幕**（預設關）；無字幕或未授權 `com.android.systemui` 作用域時該按鈕不出現。
   - 右`懸浮窗 開 / 懸浮窗 關`：單擊開關**懸浮窗**。
   - 無字幕時顯示`無字幕`且懸浮窗不可開。
   - 離開播放頁（回到首頁 / 清單頁等）按鈕自動隱藏；懸浮窗與狀態欄字幕都不隨頁面隱藏。
5. **操作懸浮窗**：面板任意處按住拖曳可移動；右下角把手拖曳可縮放。點面板（非把手）可切換右上角關閉按鈕（✕，30dp 顯示 / 點擊區）的顯示與否；點 ✕ 關閉視窗。
6. 懸浮窗字幕和狀態欄字幕可同時使用，二者互不干擾。
7. **調字幕外觀**：桌面圖示 **「DLsiteFloat 设置」** / 外掛管理員中找到本外掛 進視覺化設定頁 —— 字幕外觀是**一張卡三個頁籤**（`字幕` / `行態` / `排版`），切頁籤不丟未儲存的變更；改完點底部懸浮的「儲存設定」即生效，點錯了可在提示條上**撤銷**（狀態欄字幕的相關變更需要「重啟系統介面」才會重新整理）。
8. **想要液態玻璃效果**：同一設定頁 →「液態玻璃效果調整」卡 → 打開總開關，再依喜好調四個滑桿（**環境背景亮度**依目前頁面明暗填，其餘三項預設 `50` 即可）→ 點「儲存設定」生效。
