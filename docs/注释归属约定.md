## 2. 修正后的结论

### 2.1 「注释密度高」是**症状**，不是独立的病

| 初稿判断 | 修正后 |
| --- | --- |
| 履历寄生从 `build.gradle` 转移到了源码注释（**P0**） | ❌ **撤回**。644 个标记绝大多数是**就地设计理由的来源标记**，位置正确 |
| 应当把两个文件的叙事段搬回 `CHANGELOG.md` | ❌ **撤回**。搬走 = 拆掉 86 条铁律的出生证明；且"叙事"只占 1.3% |

**真正的因果是反过来的**：
注释之所以显得臃肿，是因为它**被迫挂在一个 404 行的方法 / 4,516 行的类上**。
结构拆分（审查报告 §2.2 / §2.4）做完之后，同样的注释会立刻变得可读。
**先拆结构，别搬注释**——顺序反了就是白干。

### 2.2 唯一站得住的搬迁候选（可选，非必须）

**带时间戳的运行时日志摘录**（全仓 141 行）。形如：

```java
//   18:20:25.879 判无字幕（cues were 55）→ 18:20:31.355 Loaded 105 cues（同一音轨，5.5s 后到）
//   17:35:02.521 判无字幕（cues were 81）→ 17:35:07.812 Loaded 152 cues（5.3s 后到）
```

这类内容是**证据**，与 `docs/修复说明/` 的卷宗同性质。搬迁方式：

1. 全量摘录进 `docs/修复说明/`（或 `CHANGELOG.md` 对应 code 条目）；
2. 代码里**只留结论 + 指针**，例如：
   ```java
   // 15000ms：cues 在手时说明本作品有字幕，值得多等。
   // 实测延迟跨度见 CHANGELOG code 942（711ms ~ 11973ms，已超 10s 窗）。
   ```
3. ⚠️ **只在"摘录占该块一半以上"时才做**。若摘录只是 20 行理由里的 2 行，搬了反而更难读。

## 3. 约定（**写下来，往后照此办理**）

### 3.1 注释该住哪：三类分工

| 类型 | 例子 | 生命周期 | 该住哪 | 现状 |
| --- | --- | --- | --- | --- |
| **不变量** | "这里必须这样，否则会 X" | 与代码同生共死 | ✅ **代码内**（就地） | 绝大部分，健康 |
| **来源标记** | `【code 1017】` + 一句"改了什么" | 过期后仅作溯源 | ✅ **代码内一行** | 644 处，健康 |
| **叙事 / 证据** | 时间戳日志摘录、录屏时刻、试错过程 | 理解后即过期 | ⚠️ `CHANGELOG.md` / `docs/修复说明/` | 141 行（1.3%），可选搬 |

### 3.2 新写注释时的三条规则

1. **就地理由必须写**——这是本项目的资产，不是负担。判据："删掉它，下一个人会不会改错？"
   会 ⇒ 写；不会 ⇒ 不写。
2. **不要粘贴 changelog 叙述**。"哪一轮、当时试了什么、为什么否掉"写成三行以内；
   超过三行就该进 `CHANGELOG.md`，代码里留指针。**不要新增长篇叙事。**
3. **来源标记写成一行**：`// 【code 1017】修 X 的根因是 Y。` —— 别把 `git blame` 的活重做一遍。

### 3.3 🔴 明确禁止的操作

| 禁止 | 原因 |
| --- | --- |
| **批量删除注释** | 里面有真不变量（铁律 #1 就出生在 `cuesOwnerSelection` 的说明里），删错 = 直接回归 |
| **批量搬迁注释块** | 取证已证明 39 个"纯叙事候选"里绝大多数是就地理由 ⇒ 搬了就是知识流失 |
| **用注释长度当重构指标** | 长度是结构的**结果**。结构没拆，注释搬走了也还在原地 |
| **只按 `【code NNNN】` 数量做统计驱动** | 644 处里 98.7% 是合法来源标记；这是个**噪音指标** |

## 5. 统计口径

| 指标 | 口径 |
| --- | --- |
| 注释行 / 代码行 / 空行 | 逐行状态机：块注释跨行计数；`//` 与 `*` 开头计注释；其余非空计代码 |
| 注释块 ≥8 行 | 连续 `//` 行 或 一个完整 `/* ... */` 块，长度 ≥8 行 |
| 历史标记 | 正则 `【(code \d+\|v\d+\|\d+\.\d+\.\d+)` |
| 日期证据 | 正则 `\d{1,2}:\d{2}:\d{2}` 或 `\d{4}-\d{2}-\d{2}` 或 `录屏\|实测\|日志实证` |
| 含时间戳的注释行 | 注释行内出现 `\d{1,2}:\d{2}:\d{2}` |
